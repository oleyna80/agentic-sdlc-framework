# Engineering Memory

This directory holds concise, verified, reusable project knowledge. It is lower
authority than current Owner instruction, `AGENTS.md`, accepted governance,
specifications/ADRs, and active Work Blocks.

Store durable decisions, source-of-truth chains, time-boxed exceptions,
reproducible verification/recovery knowledge, and recurring evidence-backed
failure patterns. Do not store secrets, private data, raw transcripts, hidden
reasoning, one-off task noise, or facts cheaper to verify live.

At non-trivial closeout classify reusable knowledge as `promoted` (this
directory), `operational-only` (`memory_bank/` or evidence report), or
`not-applicable`. Every durable entry names its authority, evidence/verification
date, owner, and review trigger. Retrieval begins with current higher authority;
if memory conflicts or may be stale, verify current sources before relying on it.
