# Skill Routing Index

The repository-root [`skills/`](../../skills/) directory is the canonical skill
library. This file indexes procedures for framework work; it does not copy,
mirror, install, lock, or activate a skill. Skills provide procedures only;
authority and write permission remain with `AGENTS.md`, accepted governance,
the active Work Block, and approved write-set.

| Procedure | Use when |
| --- | --- |
| `technical-discovery` | Define needs repository or authority evidence. |
| `architecture-discovery` | A read-only design/dependency recommendation is needed. |
| `task-decomposition` | The Orchestrator needs bounded staged work. |
| `critic-review` | Resolving the pre-execution Critic gate. |
| `scoped-coder` | One Coder executes an approved write-set. |
| `reviewer` | A frozen subject needs read-only review. |
| `verifier` | Acceptance needs reproducible assurance evidence. |
| `memory-bank-manager` | Memory retrieval or governed update is required. |
| `ssot-sync-closeout` | Required closeout synchronizes authoritative records. |
| `subagent-mission-brief` | A delegation needs an explicit bounded mission. |

Select other root-library procedures only when their documented trigger applies.
Adding, modifying, mirroring, locking, importing, or enabling skills remains a
separate approved Work Block.
