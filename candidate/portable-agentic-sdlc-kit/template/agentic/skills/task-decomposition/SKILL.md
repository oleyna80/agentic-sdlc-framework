# Task decomposition

Trigger: a plan needs independently checkable tasks. Inputs: approved plan and
write-set. First decide outcome cohesion: work belongs in one Work Block only
when it shares one verifiable outcome and coherent risk, write-set, and assurance
boundary. Do this before choosing task granularity.

Keep related tasks together when they share that boundary. Require a separate
Work Block only for an independent deliverable, distinct Owner approval or Hard
Stop, conflicting writer ownership or write-set, a separate rollback boundary,
or an independently verifiable assurance chain. Task, file, agent, and elapsed-
time counts are not split triggers.

Then assign one writer and define each task's input, output, check, handoff, and
stop condition. Outputs: tasklist and handoffs. Stop: overlapping writers,
uncovered risk, or a required split without separate authority. This procedure
grants no authority.
