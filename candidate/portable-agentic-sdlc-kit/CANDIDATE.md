# Candidate boundary

This Portable Agentic SDLC Project Kit is a draft, noncanonical and unpromoted
candidate with no current authority in this repository. WB-CORE-004 provides a
local, collision-safe installer for the candidate payload only; installation
does not promote the candidate, create a release, or grant it canonical
authority.

The package is identified by its repository revision and
`package-manifest.json`, not by a public archive or SemVer release. It contains
only the portable template, installer tooling, and deterministic tests. It does
not create runtime agents, hooks, plugins, MCP configuration, provider
directories, model-routing profiles, capability profiles, or duplicate skill
mirrors.

Root `bootstrap/**`, root `FILE_REGISTRY.yml`, and root `PROJECT_MAP.md` remain
outside this candidate-owned boundary. Promotion or archival remains reserved
for a separately Owner-approved Work Block.
